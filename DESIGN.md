# Design & Motion Specification (DESIGN.md)
## Архитектура премиального UI/UX: Ликвидация «нейрослопа» и шаблонов

> **Цель документа:** Сформировать дизайн-код и анимационную хореографию для **AI Social Content Studio**, исключающую типовой «нейрослоп» (дешевые фиолетовые градиенты, плоские карточки, скучные спиннеры, статичные переходы). Проект должен выглядеть как высококлассный нативный продукт уровня *Apple Design Awards*, с живой пружинной физикой, кинематографичной эстетикой и тактильным откликом.

---

## 1. Анти-нейрослоп Манифест (Anti-AI-Slop Manifesto)

| Что считается «нейрослопом» (Запрещено ❌) | Наше премиальное решение (Стандарт ✅) |
| :--- | :--- |
| **Фиолетово-синие «AI» градиенты и неоновые рамки** | **Warm Quiet Luxury:** Теплая льняная палитра (`#F8F5F0`), глубокий эспрессо-графит (`#181615`), акценты благородного матового золота/шампанского (`#C5A880`). |
| **Мертвые, статичные карточки с базовой тенью** | **Живая тактильная бумага:** Тончайшая аналоговая микрозернистость (Noise overlay), адаптивная глубина при тапе, пружинное сопротивление (Rubber banding). |
| **Вращающийся кружок-спиннер на всю страницу** | **Кинетический прогресс:** Дышащая аура генерации (breathing glow), бегущая световая полоса золота, плавный стриминг текста с кареткой-звездой `✦`. |
| **Мгновенное переключение экранов без анимации** | **Fluid Page & Sheet Morphing:** Экраны вытекают друг из друга с физикой вытеснения, шторки плавно открываются с затуханием по законам пружины (Spring physics). |
| **Однотипные скучные кнопки** | **Pill-Capsules со встроенными микро-орбитами:** Капсульные кнопки с отдельным белым ядром для стрелки `→`, которая поворачивается или выстреливает при генерации. |
| **Сухой интерфейс без ощущений** | **Мультисенсорный опыт:** Тактильные паттерны вибрации (Haptic Vibration API) и опциональные деликатные звуки щелчка (ASMR micro-sounds). |

## 2. Динамическая палитра и материалы (Materials & Surface Physics)

### 2.1. Физика слоев и материалов
1. **Базовый холст (Linen Canvas):**
   - Цвет: `#F8F5F0`.
   - Текстура: ультра-легкий CSS-шум (`opacity: 0.025`, `mix-blend-mode: overlay`), создающий ощущение дорогой плотной бумаги или матового пластика.
2. **Контрастный эспрессо-слой (Dark Obsidian Obsidian):**
   - Цвет: `#181615`.
   - Используется для шапки, главных кнопок и карточек «High-Impact».
3. **Белые парящие карточки (Floating Alabaster):**
   - Цвет: `#FFFFFF`.
   - Граница: `1px solid rgba(25, 23, 21, 0.06)`.
   - Тень: Двухуровневая мягкая тень:
     - `box-shadow: 0 4px 12px rgba(24, 22, 21, 0.03), 0 20px 40px -10px rgba(24, 22, 21, 0.05);`
4. **Акцентное золото (Champagne Bronze):**
   - Цвет: `#C5A880`, градиент подсветки `linear-gradient(135deg, #DFCAAE 0%, #C5A880 100%)`.

## 3. Хореография анимаций и переходов (Motion Choreography)

Все анимации базируются на библиотеке **Framer Motion** с физическими пружинами вместо линейных кривых Безье:

```typescript
// Конфигурации физических пружин
export const springPhysics = {
  snappy: { type: "spring", stiffness: 450, damping: 32, mass: 0.8 },
  gentle: { type: "spring", stiffness: 280, damping: 26, mass: 1 },
  bouncy: { type: "spring", stiffness: 500, damping: 22, mass: 0.9 },
  sheet:  { type: "spring", stiffness: 350, damping: 35, mass: 1.1 }
};
```

### 3.1. Переключатель платформ (Liquid Pill Morph)
- Переключатель соцсетей (`Telegram`, `Instagram`, `YouTube`) не просто меняет цвет:
- Активная черная плашка скользит между кнопками с помощью `layoutId="activePlatformTab"`.
- При переключении иконка выбранной платформы делает легкий микро-подскок (scale: `[1, 1.25, 1]`) с легкой вибрацией.
- Фон поля ввода идеи мягко подстраивается под атмосферу соцсети (едва заметный теплый голубоватый, градиентный розовый или глубокий рубиновый микро-акцент границы).

---

### 3.2. Раскрытие аккордеона контекста бизнеса (Elastic Accordion)
- Раскрытие блока «О вашем бизнесе»:
  - Круглая иконка `+` плавно поворачивается на 45 градусов, превращаясь в `×` со пружинным масштабированием.
  - Контент выкатывается не просто по высоте (`height: auto`), а с каскадным проявлением внутренних элементов (`staggerChildren: 0.04s`, `y: [12, 0]`, `opacity: [0, 1]`).
  - При закрытии поле сворачивается в компактный элегантный бейдж с заполненным статусом: *«Бренд: Клиника косметологии ✓»*.

---

### 3.3. Карточки вариантов: Свайп-карусель с инерцией (Physics Swipe Carousel)
- Карточки 3 вариантов постов (`Продающий`, `Сторителлинг`, `Экспертный`):
  - Полноценный жестовый свайп (drag: `"x"` с ограничением `dragConstraints` и упругим сопротивлением резинки).
  - При свайпе неактивные карточки сзади слегка уменьшаются (scale: `0.94`), размываются (`blur: 2px`) и смещаются по оси Y на `8px`, создавая эффект объемной стопки карточек.
  - Переключение точек пагинации (Dots indicator): активная точка вытягивается в овальную капсулу (ширина `8px` → `24px`), как в нативных презентациях iOS.

---

### 3.4. Живой Typewriter & Particle Glow (Анимация потоковой генерации)
- Пока Gemini стримит текст:
  - Вместо статичного курсора — живая мерцающая звездочка `✦` золотистого цвета с микро-свечением.
  - По мере генерации каждый новый блок (Заголовок → Текст → CTA → Теги) появляется не рывком, а плавно «всплывает» из легкого размытия:
    ```css
    filter: blur(4px) -> blur(0px);
    transform: translateY(6px) -> translateY(0px);
    ```
  - Верхняя панель карточки пульсирует теплым световым градиентом в стиле «живого дыхания» (Breathing Aura: 2.4s цикл).

---

### 3.5. 1-Click Copy: Анимация «Тактильного взрыва» (Copy Micro-Celebration)
- При нажатии на кнопку «Скопировать весь пост»:
  1. **Фаза нажатия (0-50ms):** Кнопка сжимается до `scale: 0.94`, срабатывает двойной виброотклик смартфона.
  2. **Фаза жидкого наполнения (50-200ms):** Кнопку заливает мягкая золотистая волна слева направо.
  3. **Фаза морфинга иконки:** Стрелка `→` плавно раскручивается и превращается в зеленую галочку `✓`.
  4. **Фаза вылета тоста:** Снизу плавно с пружиной вылетает капсульный тост:
     > `✨ Полный пост скопирован в буфер! Готов к публикации`
  5. Спустя 2 секунды кнопка с упругой пружиной возвращается в исходное состояние.

## 5. Детализация микровзаимодействий (Micro-interactions)

1. **Реактивные инпуты:** При фокусе на textarea поле не просто подсвечивается — граница мягко увеличивает контраст, а плейсхолдер плавно растворяется вверх.
2. **Чипы быстрых тем (`[ + Акция ]`, `[ + Ошибка ]`):** При клике на чип текст идеи влетает в текстовое поле с анимацией частицы, чип кратковременно подсвечивается золотом и отключается.
3. **Модульное копирование блоков:** Наведение/тап на блок (хук или хэштеги) проявляет аккуратную круглую кнопку копирования. При клике над кнопкой на 1 секунду всплывает мини-бейдж `Скопировано!`.
4. **Индикатор силы хука (Hook Energy Bar):** Под сгенерированным заголовком отображается минималистичный микро-индикатор виральности хука (3 деления золотого цвета), усиливающий ощущение авторской работы.

## 7. Утвержденные проектные решения (Design Consensus)

1. **Цветовая тема:** Теплая льняная по умолчанию (`#F8F5F0`) с мгновенным переключением на глубокую темную эспрессо-тему (Dark Obsidian `#181615`).
2. **Характер анимаций:** Плавные, кинематографичные и медитативные (Editorial Flow, damping: 28, mass: 1).
3. **Плотность интерфейса:** Компактная эргономика (минимизация холостого скролла на мобильных экранах).
4. **Текстурный фон:** Тончайшая матовая аналоговая зернистость (Noise overlay, эффект премиальной бумаги).
5. **Навигация по 3 вариантам:** Элегантные вкладки-пилюли с плавающим `layoutId` индикатором над карточкой.
6. **Потоковый рендеринг (Streaming):** Плавное каскадное всплытие готовых смысловых строк и блоков (Fade & Slide up).
7. **Звуковой дизайн (ASMR Audio):** Деликатные приглушенные звуки тапов и щелчка при копировании с тумблером звука (Sound Toggle Mute/Unmute) в шапке.
8. **Иконки платформ:** Цветные нативные бейджи (Telegram Cyan, Instagram Sunset Gradient, YouTube Red).
9. **Визуализация силы хука:** Индикатор энергии заголовка (Hook Energy Meter) с 3 золотыми делениями.
10. **Главная кнопка действия:** Фиксированная плавающая капсула в нижней зоне экрана (Thumb Sticky Dock, всегда под большим пальцем).
